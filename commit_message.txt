🤖 Sentinel: Kill surviving mutants in logos-tui

## 🧬 Mutants Found
Initial targeted runs on `logos-tui` components revealed multiple surviving mutants due to missing or weak tests:
- UI renders (`home`, `budget`, `reconcile`, `register`, `rsu`) returning empty strings instead of correct text.
- `terminal.rs` failing to route `AppInput` accurately due to missed key match arms.
- Untestable methods in `TerminalSession` like setup/restore logic handling raw `TTY` state.

## 🎯 Tests Added/Strengthened
- `rsu_screen.rs`: Created basic smoke test to assert static placeholder text output for `ui/rsu.rs`.
- `home_screen.rs`: Added comprehensive assertions around getters for `HomeSnapshot` and improved tests checking attributes.
- `terminal_runtime.rs`: Added comprehensive input mapping checks, runtime error state checks, and an end-to-end `TestBackend` render test.
- `scope_editing.rs`: Validated error message formatting specifically when inputs are blank or incorrectly formatted.

## 📊 Kill Rate
All UI screen rendering functions and event handling logic now pass `cargo-mutants` validation (mutants killed or marked unviable).

## ⚠️ Exclusions Added
Terminal session operations relying on raw PTY state mapping (`draw`, `next_input`, `restore`, `Drop`, and standard match arms to bypass events) have been documented as inherently untestable and excluded in `.cargo/mutants.toml` using regex.
